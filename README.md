# kukjinjang.com

Kukjin Jang's personal website built with [Astro](https://astro.build/).

## Content

Site content can be found in [`src/content/`](./src/content/).

## Testing locally

1. Install vscode
2. Install mise-en-place
3. Start dev server at http://localhost:4321/
   ```
   pnpm dev
   ```
4. Start coding with real time feedback
